tempo request https://parallelmpp.dev/api/responses \
  --request POST --header 'Content-Type: application/json' \
  --data @parallel-request.json --max-spend 0.01 \
  --network mainnet --payment-intent charge \
  --payment-token USDC.e

The same trial, in your agent.

Add this MCP server to a compatible agent. Requires Node 22.22 or later.

{
  "mcpServers": {
    "research-pass": {
      "command": "npx",
      "args": [
        "--yes",
        "--package",
        "github:lcusack/parallel-research-pass",
        "parallel-research-pass"
      ]
    }
  }
}

Then ask your agent:

Use Research Pass to verify my World ID, research what Parallel does, and show my remaining allowance.

Approve World ID in the agent too. Your remaining answers follow the same account across browser and agent sessions. Keep the MCP connection open during approval.

Installation details
How it works

World ID verifies eligibility. Parallel researches your question. This demo pays Parallel through MPP on Tempo, and you get the answer, sources, and payment receipt.

Each World ID account gets up to 10 answers while the shared budget lasts. Selfie Check or stronger is accepted. A provider could offer its own verified-human trial using the same flow.
